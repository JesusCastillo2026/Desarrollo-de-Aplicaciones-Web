# Semana 08 — Laboratorio 08 y Evaluación 2

En esta semana se incluyen dos entregas independientes: la **Evaluación 2** del Sistema de Gestión Quirúrgica y el **Laboratorio 08** sobre pruebas automatizadas y mantenimiento de la API de productos.

## Laboratorio 08 — Implementación de Tests

- [Proyecto del laboratorio](Laboratorio%2008/lab08-tests-categorias/)
- [README, instrucciones, endpoints y pruebas](Laboratorio%2008/lab08-tests-categorias/README.md)
- [Informe PDF del laboratorio](Laboratorio%2008/lab08-tests-categorias/LAB08_Implementacion_de_Tests.pdf)

El laboratorio continúa el proyecto de productos de la Semana 05. Añade pruebas unitarias e integración para productos y desarrolla el CRUD de categorías con validación, manejo de errores y pruebas propias. La base de pruebas usa H2 en memoria; el funcionamiento normal se conecta a MySQL de XAMPP y a `laboratorio_productos`.
