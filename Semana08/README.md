# Semana 08 — Laboratorio 08 y Evaluación 2

En esta semana se incluyen dos entregas independientes: el **Laboratorio 08**, sobre pruebas automatizadas y mantenimiento de una API de productos, y la **Evaluación 2**, que amplía el Sistema de Gestión Quirúrgica.

## Laboratorio 08 — Implementación de Tests

- [Proyecto del laboratorio](Laboratorio%2008/lab08-tests-categorias/)
- [README, instrucciones, endpoints y pruebas](Laboratorio%2008/lab08-tests-categorias/README.md)
- [Informe PDF del laboratorio](Laboratorio%2008/lab08-tests-categorias/LAB08_Implementacion_de_Tests.pdf)

El laboratorio continúa el proyecto de productos de la Semana 05. Añade pruebas unitarias e integración para productos y desarrolla el CRUD de categorías con validación y manejo de errores. Las pruebas usan H2 en memoria; la aplicación local utiliza MySQL de XAMPP y la base `laboratorio_productos`.
