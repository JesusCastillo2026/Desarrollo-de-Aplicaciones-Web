# Evaluación — Semana 04

## Objetivo
Implementar el módulo de solicitudes quirúrgicas para registrar y gestionar solicitudes originadas desde consulta médica, hospitalización o emergencia.

## Cómo se logró
Se organizó la aplicación en controladores, servicios, repositorios y entidades. El sistema relaciona solicitudes con pacientes, médicos e historias clínicas, maneja estados y prioridades, ofrece endpoints REST y presenta vistas MVC para registrar y administrar solicitudes.

## Herramientas
Java 17, Spring Boot, Spring Web MVC, Spring Data JPA, MySQL, Thymeleaf, HTML, Bootstrap, Maven y Postman, de acuerdo con la documentación del proyecto.
