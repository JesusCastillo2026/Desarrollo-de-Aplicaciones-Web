# Semana 04

## Objetivo
Organizar el laboratorio y la evaluación de la semana. La evaluación consiste en crear un sistema para registrar y administrar solicitudes quirúrgicas.

## Cómo se logró
La evaluación implementa una aplicación con arquitectura en capas: controladores REST y MVC, servicios, repositorios y entidades. Permite registrar solicitudes vinculadas con pacientes, médicos e historias clínicas, consultar solicitudes y gestionar su estado. También incluye vistas web para el flujo de trabajo.

## Herramientas
Java 17, Spring Boot, Spring Web MVC, Spring Data JPA, MySQL, Thymeleaf, HTML, Bootstrap, Maven y Postman (según el README del proyecto).
