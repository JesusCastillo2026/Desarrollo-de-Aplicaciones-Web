# Semana 05 — Laboratorio 05: API de productos

## Objetivo
Construir una API REST para administrar productos con persistencia en base de datos, validación de datos y manejo de errores.

## Cómo se logró
Se implementó un controlador REST para listar, consultar, crear, actualizar, buscar y eliminar productos. La lógica se separó entre controlador, servicio, repositorio, modelo y DTO. Se incorporó validación de entradas y manejo global de excepciones. El proyecto incluye además componentes de auditoría mediante aspectos.

## Herramientas
Java 17, Spring Boot, Spring Web MVC, Spring Data JPA, Bean Validation, MySQL, Maven y Spring Boot DevTools. La configuración del proyecto conecta con MySQL.
